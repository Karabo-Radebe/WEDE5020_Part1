# Moja Constructions Website

## Project Overview
This project is a website developed for Moja Constructions, a construction company. The website provides information about the company, its services, completed projects and contact details.

## Website Pages
- **Home:** Introduces the company and provides an overview of its services.
- **About:** Provides information about the company.
- **Services:** Displays construction services and includes a service search feature and FAQ accordion.
- **Projects:** Displays completed projects with an image lightbox feature.
- **Contact:** Allows visitors to contact the company through a validated contact form.
- **Enquiry:** Allows potential customers to submit project enquiries.

## Features
- Interactive service search and filtering.
- FAQ accordion.
- Project image gallery with lightbox functionality.
- CSS animations and hover effects.
- Contact form validation.
- Project enquiry form.
- Responsive website layout.
- SEO meta descriptions and keywords.
- Descriptive image alternative text.
- Internal page links.
- XML sitemap and robots.txt file.

## Technologies Used

## How to View the Website
1. Download or clone the project repository.
2. Open the project folder.
3. Open `home.html` in a web browser.
